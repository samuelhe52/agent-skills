# Agent skills

A collection of skills I use with coding agents. Each directory under `skills/` can be installed as a skill on its own.

## Install

Install a specific skill with [`npx skills`](https://www.npmjs.com/package/skills):

```sh
npx skills add samuelhe52/agent-skills --skill test-value-audit
# or:
npx skills add samuelhe52/agent-skills --skill remote-gpu-experiments
```

## Skills

- `test-value-audit`: Find low-value tests and gaps in meaningful coverage.
- `remote-gpu-experiments`: Run and monitor ML workloads on remote GPU hosts.
